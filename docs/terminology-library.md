# 术语库：按领域管理词汇

术语网络的配置单位是领域，而不是每个词之间的连线。把词条放入对应领域，即可使用该领域的规则；同一领域的一万个词和十个词采用相同的配置方式。

## 常用操作

- **添加词条**：选择或搜索领域，填写词语和译法后保存。可以在表单内新建领域，也可以“保存并继续添加”，沿用领域和启用规则。
- **批量粘贴**：选择领域，粘贴每行一个词的列表，或从表格复制词语、译法两列。预览新增数量、重复项和错误行后一次导入，已有译法不被覆盖。
- **批量整理**：选中词条后，可启停、移动领域或统一使用领域规则。移动时自动使用目标领域规则。

## 领域规则

- **继承上级规则**：子领域沿用最近一个明确配置的上级领域。根领域没有上级时使用直接匹配。
- **直接匹配**：无需话题提示词，系统按当前文本与模型预算选择相关词条。
- **按话题启用**：每行填写一个主题提示词，任意语言均可。出现任一提示词即可启用领域；随后命中领域词条可以延续话题，无关会话增多后自动淡出。

例如“航天”领域配置 `航天`、`spaceflight`，其“部件”和“任务”子领域选择继承。以后导入到这些领域的词条都会自动加入同一套规则。某个子领域需要其他条件时，在该子领域覆盖规则即可。

默认打开球形节点网络：大球表示领域并显示词条数量，点击领域展开小词汇球，点击词汇即可编辑。连线由领域层级和词条归属自动生成，不需要手动配置词与词的连接。添加、批量粘贴、领域规则仍在同一工作区操作。

海量词汇按领域聚合，画布只显示有限的词汇预览，并标明当前展示数与匹配总数。搜索直接在网络中定位任意词条，不受预览数量限制，也不会跳回列表；滚轮、缩放按钮或双指手势可调整视野。需要批量整理时再打开词条视图。网络复用搜索索引，列表仅绘制可见行。

## 识别纠错与热词

词条里的“常见误识别”按语言填写，每行一种写法。例如标准词 `femboy` 的英文误识别填写 `fanboy`。词条在当前领域规则下生效时，识别结果里的 `fanboy` 会纠正为 `femboy`；提供给识别模型的热词始终是标准词，不包含误识别写法。

领域规则只决定何时启用，误识别写法跟随词条保存。切换继承、批量应用领域规则或移动领域不会丢失它们。按话题启用的领域仍需话题证据，误识别不会绕过领域规则。搜索误识别写法也能找到对应标准词。

旧数据库会自动把已启用的旧纠错别名关联迁移到词条属性，保留原来的启用规则；已停用的旧关联仍保留在高级视图中。删除误识别并保存后，旧连线不会使它重新出现。正常词汇网络只展示词条，旧的提示词节点仍可在高级关联视图查看。

当前与近期命中的标准词优先获得有限的识别提示容量，避免大领域中靠后的词长期进不了热词。多个当前生效词条把同一种写法指向不同标准词时，系统保留原文，不任意选择替换。

XR-Corpus 负责领域选择和纠错候选，主程序沿用现有的纠错结果、词汇列表和模型能力适配接口，无需了解球形节点、别名编辑或领域继承的实现。

## 已有规则与特殊词条

旧词条的独立规则在升级后保留。保存领域规则时，可选择“让现有词条也使用领域规则（含子领域）”，一次统一已有词汇。子领域自己的规则配置仍然保留。

少量特殊词条可以取消“使用领域规则”，设置独立提示词与语境条件。逐词关联位于网络视图的高级菜单中；拖拽连线会进入词条草稿，保存后才生效。

领域、词条和规则共同影响是否启用。停用领域会连同其子领域暂停生效，保存的数据不会被删除。主题提示词仅用于识别话题，不会被当作词条译法或识别纠错内容。
