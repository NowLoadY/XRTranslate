# 媒体播放与界面响应

Linux 的 MPV 视频线程与 wgpu 共用 EGL 上下文。如果等待音频时钟时持有图形锁，
即使隐藏视频，其他页面的滚动和绘制也会阻塞。界面同步查询播放器属性或等待视频线程
完成同样会把交互响应绑定到播放进度。

维护播放器时保留以下边界：

- 可见和隐藏提交都关闭 MPV 内部的目标时间等待，由播放器通知新帧。
- 播放状态由属性事件维护快照，界面读取快照并异步提交控制操作。
  文件加载、音视频参数变化及重新就绪时合并补充快照请求，补齐嵌套属性通知。
- Linux 视频提交最多保留一个未完成任务，界面复用现有纹理。
  调整大小先等待旧提交完成，销毁先退出并回收视频线程。
- 隐藏更新合并通知，防止积压；音频滤镜只随文件加载或路由变化更新，
  避免在播放重启事件中反复设置而形成循环。

离开媒体页仍可继续播放。验证需覆盖后台播放、切页、缩放、暂停、重复打开、EOF 重播
及异步加载失败；UI Director 往返延迟不等同于显示帧率。原生图形行为需在目标平台验证。
